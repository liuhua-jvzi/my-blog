# 第四章-树和二叉树

&emsp;&emsp;树是**一对多**的层次结构；**二叉树**是最常用的树，每个结点最多两个孩子，而且分左右。本章只抓考试重点：五个性质、四种遍历、完全二叉树编号、哈夫曼树和二叉排序树。

## 一、先认识几个词

| 名词 | 一句话 |
|------|--------|
| 根 | 最上面的结点，没有父结点 |
| 父 / 子 | 上下相邻；上面是父，下面是子 |
| 兄弟 | 同一个父结点的孩子 |
| 度 | 一个结点有几个孩子；树的度 = 最大度数 |
| 叶子 | 度为 0 的结点 |
| 深度 / 高度 | 从根往下数，根是第 1 层 |

> 树中每个结点最多一个父结点；不同子树互不相交。

## 二、二叉树

### 1. 二叉树的特点

- 每个结点**最多 2 个孩子**（度只能是 0、1、2）
- **左右孩子有顺序**，不能颠倒
- 只有一个孩子时，也要分清是左孩子还是右孩子

<DsFigure type="binary-tree" />

图中 A 是根，B、C 是 A 的左右孩子，D、E 是 B 的孩子，F 是 C 的左孩子。

### 2. 五个必背性质

| 性质 | 结论 |
|------|------|
| 第 i 层最多几个结点 | `2^(i-1)` 个 |
| 深度为 h 最多几个结点 | `2^h - 1` 个 |
| 叶子 n0 和度 2 结点 n2 的关系 | `n0 = n2 + 1` |
| 完全二叉树的高度 | `⌊log2 n⌋ + 1` |
| 完全二叉树编号关系 | 左孩子 `2i`，右孩子 `2i+1`，父结点 `⌊i/2⌋` |

> 题库里常考：
> - 第 5 层最多 `2^4 = 16` 个；深度 5 最多 `2^5 - 1 = 31` 个。
> - 度 2 结点有 14 个 → 叶子 `14 + 1 = 15` 个。
> - 完全二叉树有 n 个结点 → 叶子 `⌈n/2⌉` 个；1001 个结点 → 501 个叶子。
> - 最后一层结点数 = `n - (2^(h-1) - 1)`；例：10 个结点，h=4，最后一层 = 10-7 = 3 个。

### 3. 满二叉树 vs 完全二叉树

| | 满二叉树 | 完全二叉树 |
|--|----------|------------|
| 定义 | 每一层都排满 | 只有最后一层可能不满，而且从左到右连续 |
| 结点数 | 深度 h → `2^h - 1` | 同样按层编号，允许最后一个位置缺 |
| 存储 | 可以用数组 | 最适合用数组 |

<DsFigure type="complete-tree" />

> 做题看到“完全二叉树”，先想编号：左 `2i`、右 `2i+1`、父 `⌊i/2⌋`。编号从 1 开始。
> 小结论：编号 i 为奇数且 i ≠ 1 时，它的左兄弟是 `i-1`。

## 三、二叉树的存储

- **顺序存储**：用数组按完全二叉树的编号存。完全二叉树不浪费；普通二叉树可能空出很多位置。
- **链式存储**：每个结点存 `data`、`left`、`right`。n 个结点一共有 `n+1` 个空指针。

> 考试一般只问：完全二叉树适合顺序存储；普通二叉树适合链式存储。

## 四、遍历（重点）

| 遍历 | 顺序 | 记忆 |
|------|------|------|
| 先序 | 根 → 左 → 右 | 根最先 |
| 中序 | 左 → 根 → 右 | 根在中间 |
| 后序 | 左 → 右 → 根 | 根最后 |
| 层次 | 一层一层，从左到右（用队列） | BFS |

用上面的二叉树：

- 先序：A B D E C F
- 中序：D B E A F C
- 后序：D E B F C A
- 层次：A B C D E F

**根据序列还原二叉树：**

- 先序 + 中序：先序第一个是根；在中序里找到根，左边是左子树，右边是右子树；递归。
- 后序 + 中序：后序最后一个是根；同样在中序里切分。
- 先序 + 后序：**不能唯一确定**（只有一个孩子时分不清左右）。

> 做题口诀：先找根，再切左右，递归处理。

## 五、树、森林转二叉树（只记规则）

- 树转二叉树：**左孩子右兄弟**。
  - 第一个孩子做左孩子；
  - 其余孩子依次做右孩子。
- 森林转二叉树：每棵树的根依次作为前一根的右孩子。

题库里两个结论：

| 问题 | 结论 |
|------|------|
| 树的根转成二叉树后，根的右指针 | **空**（根没有兄弟） |
| 森林有 3 棵树 m1、m2、m3，转成二叉树后右子树结点数 | **m2 + m3** |

## 六、哈夫曼树（重点）

**怎么建：** 每次选两个权值最小的结点合并，把新权值放回去，重复到只剩一个根。

例：权值 1、2、4、5

```
1 + 2 = 3
3 + 4 = 7
5 + 7 = 12

WPL = 3 + 7 + 12 = 22
```

<DsFigure type="huffman-tree" />

**必背性质：**

- n 个叶子 → 总结点数 `2n - 1`
- 哈夫曼树**没有度为 1 的结点**
- `WPL = Σ(叶子权值 × 路径长度)`，也等于**所有合并权值之和**
- 左 0 右 1，得到的是**前缀编码**：没有一个编码是另一个编码的前缀

> 例：编码 `(0, 1, 00, 11)` 不是前缀码，因为 `0` 是 `00` 的前缀。

## 七、二叉排序树（BST）

- 左子树所有结点 < 根 < 右子树所有结点
- **中序遍历一定是从小到大**
- 查找：比根小往左走，比根大往右走
- 平均 O(log n)；最坏 O(n)（树退化成一条单支链）

<DsFigure type="bst" />

中序序列：`20 30 40 50 60 70 80`。

> 做题：给一组数建 BST，按“左小右大”插；判断是不是 BST，就看中序是否递增。

## 八、考试易错点

1. 二叉树左右孩子不能颠倒；只有一个孩子时也要分左右。
2. `n0 = n2 + 1`，别和 `n0 + n1 + n2 = n` 搞混。
3. 第 i 层最多 `2^(i-1)`，深度 h 最多 `2^h - 1`，不要把层数和深度搞反。
4. 完全二叉树编号从 1 开始：左 `2i`、右 `2i+1`、父 `⌊i/2⌋`。
5. 完全二叉树叶子数 = `⌈n/2⌉`；1001 个结点 → 501 个叶子。
6. 先序 + 中序、后序 + 中序能还原；先序 + 后序**不能**。
7. 哈夫曼树：n 个叶子 → `2n-1` 个结点；没有度 1 结点；WPL = 合并权值之和。
8. 二叉排序树中序有序；单支树最坏 O(n)。
9. 森林转二叉树：根的右子树是第 2 棵及以后的树；三棵树 m1、m2、m3 → 右子树 `m2+m3` 个结点。

## 九、一句话总结

- **二叉树**：最多两个孩子，左右有序；`n0 = n2 + 1`。
- **遍历**：先根、中根、后根、层次；先/后 + 中序可还原。
- **完全二叉树**：左 `2i`、右 `2i+1`、父 `⌊i/2⌋`；叶子 `⌈n/2⌉`。
- **哈夫曼树**：每次合并最小的两个；n 个叶子 → `2n-1` 个结点；WPL = 合并和。
- **BST**：左小右大，中序有序；最坏单支 O(n)。
