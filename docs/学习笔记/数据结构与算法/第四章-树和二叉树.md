# 第四章-树和二叉树

&emsp;&emsp;树是**一对多**的层次结构；**二叉树**是最常用的树，每个结点最多两个孩子，而且分左右。本章只抓考试重点：五个性质、四种遍历、完全二叉树编号、哈夫曼树和二叉排序树。

## 一、先认识几个词

| 名词 | 一句话 |
|------|--------|
| 根 | 最上面的结点，没有父结点 |
| 父 / 子 | 上下相邻；上面是父，下面是子 |
| 兄弟 | 同一个父结点的孩子 |
| 度 | 一个结点有几个孩子；树的度 = 最大度数 |
| 叶子 | 度为 0 的结点 |
| 深度 / 高度 | 从根往下数，根是第 1 层 |

> 树中每个结点最多一个父结点；不同子树互不相交。

## 二、二叉树

### 1. 二叉树的特点

- 每个结点**最多 2 个孩子**（度只能是 0、1、2）
- **左右孩子有顺序**，不能颠倒
- 只有一个孩子时，也要分清是左孩子还是右孩子

<DsFigure type="binary-tree" />

图中 A 是根，B、C 是 A 的左右孩子，D、E 是 B 的孩子，F 是 C 的左孩子。

### 2. 五个必背性质

| 性质 | 结论 |
|------|------|
| 第 i 层最多几个结点 | 2<sup>i-1</sup> 个 |
| 深度为 h 最多几个结点 | 2<sup>h</sup> − 1 个 |
| 叶子 n0 和度 2 结点 n2 的关系 | `n0 = n2 + 1` |
| 完全二叉树的高度 | `⌊log2 n⌋ + 1` |
| 完全二叉树编号关系 | 左孩子 `2i`，右孩子 `2i+1`，父结点 `⌊i/2⌋` |

> 题库里常考：
> - 第 5 层最多 2<sup>4</sup> = 16 个；深度 5 最多 2<sup>5</sup> − 1 = 31 个。
> - 度 2 结点有 14 个 → 叶子 `14 + 1 = 15` 个。
> - 完全二叉树有 n 个结点 → 叶子 `⌈n/2⌉` 个；1001 个结点 → 501 个叶子。
> - 最后一层结点数 = n − (2<sup>h-1</sup> − 1)；例：10 个结点，h=4，最后一层 = 10-7 = 3 个。

### 3. 满二叉树 vs 完全二叉树

| | 满二叉树 | 完全二叉树 |
|--|----------|------------|
| 定义 | 每一层都排满 | 只有最后一层可能不满，而且从左到右连续 |
| 结点数 | 深度 h → 2<sup>h</sup> − 1 | 同样按层编号，允许最后一个位置缺 |
| 存储 | 可以用数组 | 最适合用数组 |

<DsFigure type="complete-tree" />

> 做题看到“完全二叉树”，先想编号：左 `2i`、右 `2i+1`、父 `⌊i/2⌋`。编号从 1 开始。
> 小结论：编号 i 为奇数且 i ≠ 1 时，它的左兄弟是 `i-1`。

## 三、二叉树的存储

- **顺序存储**：用数组按完全二叉树的编号存。完全二叉树不浪费；普通二叉树可能空出很多位置。
- **链式存储**：每个结点存 `data`、`left`、`right`。n 个结点一共有 `n+1` 个空指针。

> 考试一般只问：完全二叉树适合顺序存储；普通二叉树适合链式存储。

## 四、遍历（重点）

| 遍历 | 顺序 | 记忆 |
|------|------|------|
| 先序 | 根 → 左 → 右 | 根最先 |
| 中序 | 左 → 根 → 右 | 根在中间 |
| 后序 | 左 → 右 → 根 | 根最后 |
| 层次 | 一层一层，从左到右（用队列） | BFS |

用上面的二叉树：

- 先序：A B D E C F
- 中序：D B E A F C
- 后序：D E B F C A
- 层次：A B C D E F

**根据序列还原二叉树：**

- 先序 + 中序：先序第一个是根；在中序里找到根，左边是左子树，右边是右子树；递归。
- 后序 + 中序：后序最后一个是根；同样在中序里切分。
- 先序 + 后序：**不能唯一确定**（只有一个孩子时分不清左右）。

> 做题口诀：先找根，再切左右，递归处理。

## 五、树、森林与二叉树的转换

### 1. 什么是森林？

**森林是 m（m ≥ 0）棵互不相交的树的集合。** 每棵树都有自己的根，树与树之间没有边相连。

- `m = 0`：空森林。
- `m = 1`：只有一棵树，也可以看作森林。
- 把一棵非空树的**根结点删掉**，它的所有子树就组成一片森林。

例如，下面两棵树合在一起就是一片森林：

<DsFigure type="forest-example" />

### 2. 核心规则：左孩子右兄弟

普通树的一个结点可以有任意多个孩子，而二叉树最多只有左、右两个孩子。为了用二叉树表示普通树，约定：

| 二叉树中的指针 | 在原树或森林中表示 |
|----------------|--------------------|
| 左指针 `left` | 结点的**第一个孩子**（最左边的孩子） |
| 右指针 `right` | 结点的**下一个兄弟** |

这就是**左孩子右兄弟法**。

> 特别注意：转换后的“右孩子”通常不是原树中的孩子，而是原树中的**下一个兄弟**。它只是在二叉树结构中位于右侧。

### 3. 树 / 森林转二叉树（同一套步骤）

树转二叉树和森林转二叉树，规则**基本一样**：

1. **连**：**连接**第一个孩子，做它的左孩子。
2. **连兄弟**：其余孩子从左到右用**右指针**连成一条右链（每个孩子指向下一个兄弟）。

森林只多一步：**串根**——第一棵树的根用右指针指向第二棵树的根，第二棵的根再指向第三棵的根。

| 情况 | 结果 |
|------|------|
| 一棵树 | 根的右指针一定为**空**（根没有兄弟） |
| 森林 | 根的右指针指向第二棵树的根；从根顺右指针数，几个结点就是几棵树 |

**例 1：树转二叉树**

<DsFigure type="tree-to-binary" />

- A 的第一个孩子是 B → A 的左孩子是 B
- A 其余的孩子 C、D → 用右指针连成 B → C → D
- B 的孩子 E、F → B 的左孩子 E，E 的右孩子 F
- D 的孩子 G → D 的左孩子 G
- A 没有兄弟 → A 的右指针为空

**例 2：森林转二叉树**

<DsFigure type="forest-to-binary" />

1. **连**：每棵树各自按上面两步转换（T1 得到以 A 为根的二叉树，T2 得到以 H 为根的二叉树）。
2. **串根**：A 的右指针指向 H。

- 整棵二叉树的根 = **第一棵树的根**（A）
- 其余树的根全挂在右指针上：**A 的右孩子是 H**（H 不是 A 的孩子）
- 从根顺右指针数：A → H，2 个结点，森林就是 2 棵树

### 4. 二叉树转树 / 森林（同一套步骤）

二叉树转树和转森林，步骤**完全一样**，就两步：

1. **连**：**连接**左孩子的右链的所有节点。
2. **删**：**删掉**所有**右线**（父结点指向右孩子的线）。

删完只看**根有没有右线**：

| 情况 | 结果 |
|------|------|
| 根的右指针为空 | 一棵**树** |
| 根的右指针不为空 | 一片**森林**：根的右链上有几个结点，就有几棵树 |

**例 1：转成树**（第 3 小节那棵二叉树，根的右指针为空）

<DsFigure type="binary-to-tree" />

- A 的左孩子是 B，B 沿右指针走到 C、D → **A 的孩子是 B、C、D**
- B 的左孩子是 E，E 沿右指针走到 F → **B 的孩子是 E、F**
- D 的左孩子是 G → **D 的孩子是 G**
- 删掉所有右线，根 A 没有右线 → 结果是**一棵树**

**例 2：转成森林**（题库图 4-40，根的右链是 A → C → F）

<DsFigure type="binary-to-forest" />

1. **连**：A 连 D、H（B 的右链）；D 连 J（G 的右链）；E 没有右孩子，所以 C 不用连。
2. **删**：删掉 A–C、B–D、C–F、D–H、G–J。
3. **结果**：3 棵树，根是 A、C、F。

| 树 | 根 | 结构 |
|----|----|------|
| 第 1 棵 | A | A 的孩子 B、D、H；D 的孩子 G、J；G 的孩子 I |
| 第 2 棵 | C | C 的孩子 E |
| 第 3 棵 | F | 只有 F 一个结点 |

这一问的遍历：森林先序（= 二叉树先序）`A B D G I J H C E F`；森林后序（= 二叉树中序）`B I G J D H A E C F`。

### 5. 转换前后的遍历对应关系

| 原结构 | 原结构的遍历 | 转换后二叉树的遍历 |
|--------|--------------|--------------------|
| 树 | 先序遍历：先访问根，再从左到右遍历各子树 | **先序遍历** |
| 树 | 后序遍历：先从左到右遍历各子树，再访问根 | **中序遍历** |
| 森林 | 先序遍历：依次对每棵树做先序遍历 | **先序遍历** |
| 森林 | 后序遍历（有的书写成“森林中序”）：依次对每棵树做后序遍历 | **中序遍历** |

例如，第 3 小节那棵树（根是 A）的先序遍历为：`A → B → E → F → C → D → G`。

它的后序遍历，以及对应二叉树的中序遍历，都是：`E → F → B → C → G → D → A`。

记忆：**先序对先序，后序对中序。** 题目问“森林的后序遍历”，直接写对应二叉树的**中序序列**就行。

### 6. 常考结论与易错点

| 问题 | 结论 |
|------|------|
| 一棵树转成二叉树后，根的右指针 | **空**，因为根没有兄弟 |
| 森林至少有两棵树时，第一棵树的根指向哪里 | 左指针指向自己的第一个孩子，右指针指向第二棵树的根 |
| 如何判断对应的森林有几棵树 | 从根开始沿右指针走，右链上有几个结点，就有几棵树 |
| 各棵树的结点数为 `n1、n2、…、nk` | 第一棵树的根的右子树共有 `n2 + … + nk` 个结点 |
| 原树中的叶子结点有什么特点 | 转换后**左指针为空**，但右指针不一定为空 |
| 转换前后结点数是否改变 | **不改变**，只改变结点之间的连接方式 |

最容易出错的两点：

1. **右指针表示兄弟（森林里表示下一棵树的根），不表示原树中的孩子。**
2. **二叉树转树 / 森林只有两步：连左孩子的右链，再删掉所有右线。**

> 一句话记忆：**左边连第一个孩子，右边连下一个兄弟；森林各根向右串；转回去就“连左链、删右线”。**

## 六、哈夫曼树（重点）

**怎么建：** 每次选两个权值最小的结点合并，把新权值放回去，重复到只剩一个根。

例：权值 1、2、4、5

```
1 + 2 = 3   //此时剩下：3、4、5
3 + 4 = 7   //此时剩下：7、5
5 + 7 = 12
```

建好的树里，4 个叶子的路径长度分别是：5 在第 1 层，4 在第 2 层，1、2 在第 3 层（根的层数为 0）。所以

```
WPL = 5×1 + 4×2 + 1×3 + 2×3
    = 5 + 8 + 3 + 6
    = 22
```

也可以用“合并权值之和”快速验算：`3 + 7 + 12 = 22`，结果相同。

<DsFigure type="huffman-tree" />

**必背性质：**

- n 个叶子 → 总结点数 `2n - 1`
- 哈夫曼树**没有度为 1 的结点**
- `WPL = Σ(叶子权值 × 路径长度)`，也等于**所有合并权值之和**
- 左 0 右 1，得到的是**前缀编码**：集合里任意一个编码，都**不能是**另一个编码的**前缀**。（定义）

> 例：所以编码 `(0, 1, 00, 11)` 不是**前缀码**，因为 `0` 是 `00` 的前缀，`1` 是 `11` 的前缀。

> 例：所以编码 `(00, 01, 10, 11)` 是**前缀码**，因为没有单独哪个是另一个的**前缀**。

## 七、二叉排序树（BST）

- 左子树所有结点 < 根 < 右子树所有结点
- **中序遍历一定是从小到大**
- 查找：比根小往左走，比根大往右走
- 平均 O(log n)；最坏 O(n)（树退化成一条单支链）

<DsFigure type="bst" />

中序序列：`20 30 40 50 60 70 80`。

> 做题：给一组数建 BST，按“左小右大”插；判断是不是 BST，就看中序是否递增。

## 八、考试易错点

1. 二叉树左右孩子不能颠倒；只有一个孩子时也要分左右。
2. `n0 = n2 + 1`，别和 `n0 + n1 + n2 = n` 搞混。
3. 第 i 层最多 2<sup>i-1</sup>，深度 h 最多 2<sup>h</sup> − 1，不要把层数和深度搞反。
4. 完全二叉树编号从 1 开始：左 `2i`、右 `2i+1`、父 `⌊i/2⌋`。
5. 完全二叉树叶子数 = `⌈n/2⌉`；1001 个结点 → 501 个叶子。
6. 先序 + 中序、后序 + 中序能还原；先序 + 后序**不能**。
7. 哈夫曼树：n 个叶子 → `2n-1` 个结点；没有度 1 结点；WPL = 合并权值之和。
8. 二叉排序树中序有序；单支树最坏 O(n)。
9. 森林转二叉树：根的右子树是第 2 棵及以后的树；三棵树 m1、m2、m3 → 右子树 `m2+m3` 个结点。

## 九、一句话总结

- **二叉树**：最多两个孩子，左右有序；`n0 = n2 + 1`。
- **遍历**：先根、中根、后根、层次；先/后 + 中序可还原。
- **完全二叉树**：左 `2i`、右 `2i+1`、父 `⌊i/2⌋`；叶子 `⌈n/2⌉`。
- **哈夫曼树**：每次合并最小的两个；n 个叶子 → `2n-1` 个结点；WPL = 合并和。
- **BST**：左小右大，中序有序；最坏单支 O(n)。
