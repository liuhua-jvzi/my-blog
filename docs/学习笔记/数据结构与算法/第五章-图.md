# 第五章-图

&emsp;&emsp;图是**多对多**关系：由**顶点**和**边**组成。本章只抓考试重点：图的存储、DFS/BFS、最小生成树、最短路径和拓扑排序。

## 一、图的几个词

| 名词 | 一句话 |
|------|--------|
| 无向图 | 边没有方向，`(A,B)` 和 `(B,A)` 是同一条边 |
| 有向图 | 边有方向，叫弧，`<A,B>` 表示 A → B |
| 度 | 无向图中一个顶点连了几条边 |
| 入度 / 出度 | 有向图中指向它的弧数 / 从它出去的弧数 |
| 连通图 | 无向图中任意两个顶点都有路径 |
| 连通分量 | 无向图的极大连通子图 |
| 强连通 | 有向图中任意两个顶点互相可达 |
| 生成树 | 包含全部 n 个顶点、n-1 条边的极小连通子图 |
| 网 | 带权的图 |

<DsFigure type="graph" />

图中 A~F 共 7 条边；所有顶点的度数之和 = 14 = 2 × 7。

**必背小结论：**

- 无向图：所有顶点度数之和 = `2e`（e 是边数）
- 有向图：所有顶点入度之和 = 出度之和 = `e`
- 无向完全图：`n(n-1)/2` 条边；有向完全图：`n(n-1)` 条弧
- 连通无向图至少 `n-1` 条边；生成树正好 `n-1` 条边
- n 个顶点（n>1）的强连通有向图，最少 `n` 条弧（围成一个环）

## 二、图的存储

### 1. 邻接矩阵

用 n × n 的二维数组存边：

- `A[i][j] = 1` 表示有边（带权图存权值，没有边存 ∞）
- 无向图的矩阵**对称**：`A[i][j] = A[j][i]`
- 对角线一般为 0
- 空间 `O(n^2)`，适合**稠密图**

> 无向图邻接矩阵中 1 的个数 = `2e`（每条边算两个方向）。
> 无向图行和 = 度数；有向图行和 = 出度，列和 = 入度。

### 2. 邻接表

每个顶点挂一个链表，存它所有邻居：

- 空间 `O(n+e)`，适合**稀疏图**
- 无向图：链表结点总数 = `2e`
- 有向图：链表结点总数 = `e`；出度 = 链表长度，入度要另建逆邻接表

| 对比项 | 邻接矩阵 | 邻接表 |
|--------|----------|--------|
| 空间 | `O(n^2)` | `O(n+e)` |
| 适合 | 稠密图 | 稀疏图 |
| 判断两点是否有边 | O(1) | O(度数) |
| 找所有邻居 | O(n) | O(度数) |

## 三、图的遍历

| 遍历 | 用什么 | 像二叉树的 |
|------|--------|------------|
| DFS 深度优先 | 栈 / 递归 | 先序遍历 |
| BFS 广度优先 | 队列 | 层次遍历 |

- 邻接矩阵：DFS/BFS 都是 `O(n^2)`
- 邻接表：DFS/BFS 都是 `O(n+e)`
- **遍历序列不唯一**：取决于起点，以及邻接矩阵/邻接表的存储顺序。

用上面的图，假设邻接顺序是：

```
A: B, D    B: A, C, E    C: B, F
D: A, E    E: B, D, F    F: C, E
```

- 从 A 开始 DFS：`A B C F E D`
- 从 A 开始 BFS：`A B D C E F`

> 遍历时经过的边会构成一棵**生成树**，有 `n-1` 条边。

## 四、最小生成树（MST）

**是什么：** 在带权连通无向图中，选 `n-1` 条边把所有顶点连起来，并且总权值最小。

| 算法 | 思路 | 适合 | 复杂度 |
|------|------|------|--------|
| Prim 普里姆 | 从一个顶点开始，每次加入“离当前树最近”的顶点 | 稠密图 | `O(n^2)` |
| Kruskal 克鲁斯卡尔 | 边按权值从小到大排序，不形成环就加入 | 稀疏图 | `O(e log e)` |

<DsFigure type="weighted-graph" />

例：图中最小生成树是 `A-B(1) + B-C(2) + C-D(3)`，总权值 = 6。
另外两条边 `A-D(4)`、`B-D(5)` 会形成环，所以不选。

> 最小生成树可能不唯一，但总权值一定相同。

## 五、最短路径

| 算法 | 求什么 | 适用 | 复杂度 |
|------|--------|------|--------|
| BFS | 无权图单源最短路径 | 边权都相同 | `O(n+e)` |
| Dijkstra 迪杰斯特拉 | 单源最短路径 | 边权非负 | `O(n^2)` |
| Floyd 弗洛伊德 | 任意两点最短路径 | 可有负权（不能有负环） | `O(n^3)` |

**Dijkstra 一句话：** 每次选当前距离最小的未确定顶点，确定它，再用它更新邻居。

用上面的带权图，从 A 出发：

| 终点 | B | C | D |
|------|---|---|---|
| 最短距离 | 1 | 3 | 4 |

> 注意：A→D 的最短路径是直接走 `A-D(4)`，而最小生成树里没有 `A-D`。**最短路径和最小生成树不是一回事。**

## 六、拓扑排序（AOV 网）

**AOV 网：** 顶点表示活动，有向边表示“先做谁、后做谁”。

**做法：**

1. 统计每个顶点的入度
2. 把入度为 0 的顶点入队
3. 出队一个，输出它，并把它的所有后继入度减 1
4. 后继入度变成 0 就入队
5. 重复到队列为空

<DsFigure type="dag" />

上图的拓扑序列：`A B C D` 或 `A C B D`（顺序不唯一）。

- 复杂度 `O(n+e)`
- 如果最后输出的顶点数小于 n，说明图中有环，不能拓扑排序

## 七、考试易错点

1. 无向图度之和 = `2e`；有向图入度之和 = 出度之和 = `e`。
2. 无向完全图 `n(n-1)/2` 条边；有向完全图 `n(n-1)` 条弧。
3. 连通无向图至少 `n-1` 条边；生成树 `n-1` 条边。
4. 邻接矩阵空间 `O(n^2)`，只和顶点数有关；邻接表 `O(n+e)`。
5. 无向图邻接矩阵对称；有向图行和是出度，列和是入度。
6. 无向图邻接表结点数 = `2e`；有向图 = `e`（出度）。
7. DFS 类似先序，BFS 类似层次；遍历序列不唯一。
8. Prim 适合稠密图 `O(n^2)`；Kruskal 适合稀疏图 `O(e log e)`。
9. Dijkstra 不能处理负权边；Floyd 可以，但不能有负环。
10. 拓扑排序每次输出入度 0 的顶点；输出不完说明有环。
11. 连通无向图的连通分量个数是 1；强连通有向图最少 `n` 条弧。

## 八、一句话总结

- **图 = 顶点 + 边**：稠密用邻接矩阵，稀疏用邻接表。
- **遍历**：DFS 栈/递归，BFS 队列；序列不唯一。
- **最小生成树**：Prim 稠密、Kruskal 稀疏；`n-1` 条边。
- **最短路径**：BFS 无权、Dijkstra 非负、Floyd 全对。
- **拓扑排序**：入度 0 入队；有环就输出不完。
