# 第二章-线性表

&emsp;&emsp;线性表是**数据元素**的**有限序列**，是最基本的数据结构：元素排成一队，除第一个和最后一个外，每个元素都只有一个前驱和一个后继。按存储方式分两种——**顺序表**用连续内存，**单链表**用指针连接。

## 一、顺序表（顺序存储）

### 1. 是什么

用一段**地址连续**的内存依次存放元素。逻辑上相邻，物理上也相邻。

本质就是**数组**，所以支持**随机存取**：知道下标就能直接算出地址。

<DsFigure type="seq-list" />

图中 `length = 4`（存了 4 个元素），最后一个是空位；`capacity = 5` 是数组最多能装多少，可以比 length 大。

### 3. 插入和删除要移动元素

插入：先把插入位置及后面的元素整体后移一格，再把新元素放进去。

i从0开始：需要向后移动 **n-i** 个元素；i从1开始：需要向后移动 **n-i+1** 个元素

```
在下标 2 插入 99：

插入前： 10  20  30  40  _
插入后： 10  20  99  30  40
               ↑ 从后往前依次后移
```

删除：把它后面的元素整体前移一格，覆盖掉它。

i从0开始：需要向前移动n-(i+1)= **n-i-1** 个元素；i从1开始：需要向后移动n-i-1+1= **n-i** 个元素

```
删除下标 1 的 20：

删除前： 10  20  30  40
删除后： 10  30  40  _
            ↑ 从前往后依次前移
```

### 4. 时间复杂度（重点）

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按位查找 `a[i]` | **O(1)** | 直接算地址，随机存取 |
| 按值查找 | O(n) | 最坏要把 n 个元素看一遍 |
| 插入 | 平均 O(n) | 最好 O(1)（表尾），最坏 O(n)（表头），平均移动约 **n/2** 个元素 |
| 删除 | 平均 O(n) | 最好 O(1)（表尾），最坏 O(n)（表头），平均移动约 **(n-1)/2** 个元素 |

> 口诀：**查得快，增删慢。**

#### 空间复杂度

空间复杂度有两种问法，答案不一样：

| 问法 | 答案 | 说明 |
|------|------|------|
| 存下整个顺序表要多少空间？ | **O(n)** | n 个元素占 n 个位置；数组还可能预留空位 |
| 插入/删除一个元素要多少额外空间？ | **O(1)** | 只用几个临时变量（i、j、temp），和 n 无关 |

这里的 **O(1)** 指的是**辅助空间**（临时变量），不是整个顺序表占用的空间。

> 记住：**存表 O(n)，增删 O(1)**。题目问“插入/删除的空间复杂度”，答 **O(1)**。顺序表的存储密度=1。

### 5. 优缺点

- 优点：支持随机访问；按下标查元素快；不用存指针，存储密度高
- 缺点：插入/删除要移动大量元素；容量固定，扩容有开销；必须占用连续内存

## 二、单链表（链式存储）

### 1. 是什么

每个元素叫一个**结点**，结点里存两部分：

- **数据域 data**：存元素本身
- **指针域 next**：存下一个结点的地址

结点在内存里可以分散存放，靠 next 串起来，所以逻辑上相邻、物理上不一定相邻。想找第 i 个结点，只能从头一个一个走，这叫**顺序存取**。

### 3. 结点结构

C 语言：

```c
typedef struct LNode {
    int data;            // 数据域
    struct LNode *next;  // 指针域：指向下一个结点
} LNode, *LinkList;
```

Java 里就是：

```java
class Node {
    int data;
    Node next;
}
```

### 4. 插入和删除只改指针

在 p 结点后面插入 s：

```
插入前：p ──→ [ data | ● ] ──→ [ 原来的下一个结点 ]
插入后：p ──→ [ data | ● ] ──→ [ s | ● ] ──→ [ 原来的下一个结点 ]
```

关键两步，**顺序不能反**：

```c
s->next = p->next;  // 先让 s 接上 p 后面的结点（原来的下一个结点）
p->next = s;        // 再让 p 指向 s
```

删除 p 后面的结点 q：

```
删除前：p ──→ [ ● ] ──→ [ q ] ──→ [ 后面 ... ]
删除后：p ──→ [ ● ] ────────────→ [ 后面 ... ]
```

```c
q = p->next;
p->next = q->next;
free(q);   // C 语言要释放；Java 交给 GC
```

### 5. 时间复杂度（重点）

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按位查找第 i 个 | O(n) | 只能从头走 i 步 |
| 按值查找 | O(n) | 最坏要扫一遍 |
| 插入（已经找到位置） | **O(1)** | 只改几个指针 |
| 删除（已经找到前驱） | **O(1)** | 只改几个指针 |
| 插入/删除（包含找位置） | O(n) | 找位置才是大头 |

> 口诀：**增删快，查得慢**；但“快”的前提是已经站在那个位置。

#### 空间复杂度

| 问法 | 答案 | 说明 |
|------|------|------|
| 存下整个单链表要多少空间？ | **O(n)** | n 个结点，每个结点 = 数据域 + 一个指针，常数级额外开销 |
| 插入/删除一个结点要多少额外空间？ | **O(1)** | 只改几个指针 / 用 1~2 个临时指针，和 n 无关 |

这里的 **O(1)** 指的是**辅助空间**（临时指针），不是整个链表占用的空间。

> 注意：单链表每个结点多一个指针，存储密度比顺序表低，但整体仍是 O(n)。单链表的存储密度<1。

### 6. 优缺点

- 优点：插入/删除不用移动元素；不需要连续内存；长度不固定
- 缺点：不能随机访问；每个结点多一个指针，存储开销比顺序表大；找第 i 个要遍历

## 三、顺序表 vs 单链表

| 对比项 | 顺序表 | 单链表 |
|--------|--------|--------|
| 存储方式 | 连续内存 | 结点分散，指针连接 |
| 存取方式 | 随机存取 | 顺序存取 |
| 按位查找 | O(1) | O(n) |
| 按值查找 | O(n) | O(n) |
| 插入/删除 | O(n)（要移动元素） | O(1)（已定位）/ O(n)（要查找） |
| 存储整个表 | O(n)，可能预留空位 | O(n)，每个结点多一个指针 |
| 插入/删除的辅助空间 | **O(1)** | **O(1)** |
| 适合场景 | 查得多、改得少 | 改得多、查得少 |

## 四、考试易错点

1. 顺序表插入平均移动 **n/2** 个元素，删除平均移动 **(n-1)/2** 个元素，所以都是 O(n)。
2. 单链表插入/删除是 O(1) **有前提**：已经找到前驱结点；如果还要从头找位置，整体还是 O(n)。
3. 头指针 vs 头结点：
   - 头指针：指向链表第一个结点的指针，必须有；
   - 头结点：人为加在第一个结点前面的结点，数据域一般不放有效数据，带头结点能让插入/删除更统一。
4. 顺序表的 `length` 和 `capacity` 不是一回事：length 是当前元素个数，capacity 是数组能装多少。
5. 顺序表按位查找是 O(1)，但按值查找还是 O(n)，别记混。
6. 单链表不能随机访问，找第 i 个必须从头遍历。
7. 空间复杂度要分两种问法：**存整个表是 O(n)；插入/删除的辅助空间是 O(1)**。题目问“插入/删除的空间复杂度”时，别只写 O(n)。

## 五、一句话总结

- **顺序表 = 数组**：查得快，增删慢，要连续空间。
- **单链表 = 结点 + 指针**：增删快（已定位时），查得慢，不要连续空间。
- **空间复杂度**：存整个表是 **O(n)**，插入/删除的辅助空间是 **O(1)**。
